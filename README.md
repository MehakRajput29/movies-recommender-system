# 🎬 Movie Recommender System

An interactive machine learning web application that recommends movies based on vector similarity algorithms using Content-Based Filtering.

## 🚀 Features
- **Smart Recommendations:** Uses Cosine Similarity to suggest top 5 related movies.
- **Dynamic Poster Fetching:** Integrates OMDb API to fetch movie metadata and poster artwork live.
- **Modern Streaming UI:** Built with Streamlit and styled with custom CSS for a dark-mode user experience.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Streamlit, Pandas, Requests, Scikit-learn, Pickle
- **API:** OMDb API
